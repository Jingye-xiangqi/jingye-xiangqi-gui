skin.json 格式说明（给「皮肤批量转换脚本」用）
============================================================

每个皮肤文件夹（skins\皮肤名\）里放：

    background.png        桌面背景图（整块棋盘区域都用它，每套风格不同）
    board.png             可选：棋盘图（有就把棋盘画成这张图；没有就用背景 + 程序画的格线）
    ba.png bb.png ...     14 个棋子图（圆形居中，建议透明背景）
    ra.png rb.png ...
    mask.png mask2.png    可选：选中框 / 落点提示框（没有就用程序自带的）
    skin.json             对齐参数（本文件说明的就是它）

程序读 skin.json 的方式：**根据参数算出"棋盘网格"应该画在背景的什么位置**，
把 8×9 的格线画在那里，棋子按"格子 × pieceScale"贴到交叉点中心。
所以只要参数给对了，不管皮肤的边距比例是多少，都不会错位。


一、当前批量转换用的写法（推荐，比例式）
------------------------------------------------------------
{
  "board_w_ratio": 1.0,
  "board_h_ratio": 1.0,
  "margin_left": 0.0,
  "margin_top": 0.0,
  "grid_w": 0.8,
  "grid_h": 0.8
}

  margin_left / margin_top   网格左上角的位置（占背景图宽/高的比例，0~1）
  grid_w / grid_h            网格的大小（占背景图宽/高的比例，0~1）
                             例：grid_w=0.8 表示棋盘宽 = 背景宽的 80%
  board_w_ratio / board_h_ratio  棋盘区域占整块画布的比例（1.0 = 铺满，默认）

程序的实际做法：背景图铺满整个棋盘区域（拉伸到画布，不裁切、不留黑边），
然后按上面的比例算出网格位置；再自动保证四周留出约 0.6 格边距
（放坐标、避免边上的棋子被裁掉），必要时把棋盘整体往中间挪一点点，尺寸不变。
格线颜色会根据背景明暗自动选（深色背景用浅色线，浅色背景用深色线）。


二、另一种等价写法：直接给"棋盘图里网格的像素位置"（有 board.png 时用）
------------------------------------------------------------
{
  "board": "board.png",
  "grid": [59, 79, 560, 630],
  "pieceScale": 0.92
}

  board      棋盘图文件名（默认找 board.png / board.bmp / board.jpg…，可省略）
  grid       棋盘图里 **8×9 网格** 的位置，[x, y, w, h]
             x, y  = 网格左上角（最上面那条横线、最左边那条竖线的交点）在图片里的像素坐标
             w, h  = 网格的宽和高（＝最右竖线 − 最左竖线，最下横线 − 最上横线）
  pieceScale 可选，棋子图大小 = 格宽 × 这个数（默认 0.92，一般不用改）


三、grid 还可以写成这些等价形式（程序都认，挑一种最方便的）
------------------------------------------------------------
1) 左上角 + 宽高（对象写法）
   "grid": {"x": 59, "y": 79, "width": 560, "height": 630}

2) 四条边（左上右下）
   "grid": {"left": 59, "top": 79, "right": 619, "bottom": 709}

3) 左上角 + 右下角
   "grid": [[59, 79], [619, 709]]

4) 用比例（0~1，相对图片宽高）：数值都 ≤ 1.5 时程序按比例理解
   "grid": [0.0656, 0.079, 0.6222, 0.63]
   （900×1000 的图里 0.0656×900≈59，0.63×1000=630）

5) 边距 + 一格像素
   "margins": {"left": 59, "top": 79, "right": 281, "bottom": 291},
   "cell": 70
   （right / bottom 是"网格右边到图片右边"的边距）

6) 左上角 + 一格像素
   "origin": [59, 79], "cell": 70
   （cell 也可以写成 [cellX, cellY] 或 {"x": 70, "y": 70}）

键名不区分大小写、下划线和连字符：
   grid / gridRect / grid_rect / boardRect / board_rect / rect / area /
   boardArea / gridBox / frame 都当作网格位置。


三、可选的两个微调（一般不需要）
------------------------------------------------------------
{
  "adjust": {"dx": 0, "dy": 0, "scale": 100}
}
  dx / dy  整体平移，单位是"格"（0.1 就是挪十分之一格）
  scale    整体缩放百分比（100 = 原样）
  背景：极个别皮肤如果网格线不是标准 8×9（比如带额外边框装饰），
        可以用这两个值微调；正常情况下留空即可。


四、程序的容错规则（写错了也不会崩）
------------------------------------------------------------
· skin.json 不存在、读不动、或者里面的参数明显不对（格子不是方的、
  网格超出图片范围、网格占图片不到 1/4）→ 程序会自动检测棋盘图里的网格；
· 自动检测也不可信 → 退回程序自带的木纹棋盘（棋子照样能换，绝不会错位）；
· 具体走了哪条路，会写在 exe 旁边的 link_debug.log 里，例如：
    皮肤：1-Ivory｜棋子 16 张｜棋盘图 有｜对齐参数 skin.json
    皮肤：3-Ice｜棋子 16 张｜棋盘图 有｜对齐参数 无（用自带木纹棋盘）
· 转换脚本只要保证 grid 给对，78 套棋盘都能正确对齐。


五、怎么快速自检
------------------------------------------------------------
1. 打开程序 → 顶部「界面」→「棋子皮肤」区域：
     旁边会显示 skins 目录的路径和"共 N 套"；
     下拉框里选中某一套 → 棋盘立刻变成这套的棋盘图，棋子也换成这套的样式。
2. 看棋盘边缘：四个角的棋子应该正好压在棋盘图的四个角上；
   如果整体偏了，用 skin.json 的 adjust 微调（或检查 grid 是否量的是网格线交点）。
3. 点「刷新」可以重新扫描 skins 目录（转换脚本边跑边刷新即可看到新皮肤）。
