静夜象棋界面（QQ:3375227582）—— 使用说明
============================================

本说明写给普通用户，尽量少用技术词汇。照着一步一步做就行，看完第一、二节你就能开始用了。

当前版本：1.6（这一版改了什么，见同目录下的「更新日志.txt」）


一、这个软件是什么，能干什么
------------------------------------------------

「静夜象棋界面」是一个中国象棋的**桌面程序**（不是网页，不用打开浏览器）。
双击文件夹里的「静夜象棋界面.exe」就会弹出一个独立窗口，关掉窗口程序就退出了。
它不需要安装 Python，也不需要联网（只有用「云库」时才需要联网）。

主要能干这几件事：

  · 打谱复盘：打开别人下过的棋谱（XQF / PGN 格式）一手一手看，可以前后翻、自动播放、
    在任意一手上写评注、把某一手设成主线或者删掉分支（也就是"变例"）。
  · 人机对战：让皮卡鱼引擎当你的对手，你走红方或黑方都行。
  · 局面分析：让引擎一直算，实时告诉你最佳着法、评分、胜率，帮助你判断局面好坏。
  · 开局库：加载 OBK / PFBOOK 等开局库，软件会告诉你这个局面库里推荐走哪几步、
    各自出现多少次、胜率多少；打开「启用库招」后，引擎会自动按库里的招法走。
  · 云库：连到网上的"中国象棋云库"，查这个局面别人都怎么走、胜率多少。
  · 编辑局面：自己想摆一个局面来研究（左键放子、右键删子），也可以直接粘贴 FEN 局面代码。
  · 局面图片：把当前棋盘导成图片；反过来，把一张棋盘截图丢给软件，它能自动认出来是什么局面。
  · 换皮肤：用你自己的棋盘图和棋子图，或者切换软件自带的几套配色。


二、第一次打开怎么用（3 分钟上手）
------------------------------------------------

  1. 双击「静夜象棋界面.exe」，等一两秒，窗口就会出现
（标题栏写着"静夜象棋界面1.6（QQ:3375227582）"）。

  2. 引擎会自动加载：程序会在自己旁边的 engine 文件夹里找皮卡鱼引擎（pikafish.exe），
     找到就自动加载。窗口右下角会显示"引擎：Pikafish …"，右栏会亮起一个小圆点。
     如果显示"未加载引擎"，看下面第 5 节或第 10 节「常见问题」。

  3. 想下盘棋？点顶部的「引擎执黑」（让引擎走黑方，你走红方），然后用鼠标在棋盘上走子：
     点一下自己的棋子（会出现绿点表示能走到哪里、红圈表示能吃掉哪个子），再点目标位置就落子；
     也可以直接把棋子拖到目标位置。轮到你走时你就走，轮到引擎它会自己思考、自己走。

  4. 想复盘？点顶部「打开棋谱」，选一个 .xqf 或 .pgn 文件，然后用「首 / 上一步 / 下一步 / 末」
     或键盘的 ← → 逐手看，也可以点「播放」自动放。

  5. 想自己摆局面研究？点顶部「编辑局面」，用左边的棋子画笔点棋盘摆子（右键擦掉棋子），
     再点「开始对局」。

  就这么多，剩下的功能可以慢慢看下面的说明。


三、界面介绍（从上到下、从左到右）
------------------------------------------------

【顶部工具栏】两行，都靠左排（按钮多，窗口窄也挤不掉）：

  第一行最左边是**带文字**的设置类按钮：
    界面 / 引擎 / 开局库 / 连线 / 连线设置 / 断开 / 恢复出厂
      · 界面 —— 背景、开关、主题、棋盘大小、棋子皮肤（见第七节）。
      · 连线设置 —— 连线相关设置全在这一个窗口里（扫描间隔 / 点击节奏 /
        识别模型 / 棋盘区域 / 确认方式 / 开始连线）。
      · 引擎 —— 引擎路径与引擎自身的 UCI 选项（见第五节）。
      · 开局库 —— 本地开局库与云库设置（见第六节）。
      · 连线 / 断开 —— 连到别的象棋平台 / 取消连线（见第八节）。
      · 恢复出厂 —— 删掉 settings.json，所有设置回到默认值（会先弹确认框）。

  接着是一排**图标按钮**：按钮上只有图案、没有文字，鼠标停上去会显示名字与快捷键。

    第一行（文件 + 模式）：
      加号＝新建棋局    文件夹＝打开棋谱    软盘＝保存棋谱
      红点＋箭头＝引擎执红    黑点＋箭头＝引擎执黑    放大镜＝分析模式

    第二行（播放 + 局面）：
      双竖线＋三角＝首步    左三角＝上一步    红三角＝播放（播放中变方块）
      右三角＝下一步    三角＋双竖线＝末尾    左箭头＝悔棋    右箭头＝重做
      铅笔＝编辑局面    两个方块＝复制局面(FEN)    剪贴板＝粘贴局面/棋谱
      文稿＋红方块＝复制棋谱    上下箭头＝翻转棋盘

    ★ 图标按颜色分组，好记：
      · 蓝色＝文件（新建 / 打开 / 保存）
      · 红、黑、金色＝三种模式（引擎执红 / 引擎执黑 / 分析模式）；
        **选中的模式整块变红**，再点一次取消，都不选＝纯手动打谱
        （引擎不自动走子、也不自动分析，双方都自己走）。
      · 绿色＝播放（首步 / 上一步 / 播放 / 下一步 / 末尾 / 悔棋 / 重做）
      · 紫色＝局面（编辑 / 复制局面 / 粘贴局面·棋谱 / 复制棋谱 / 翻转棋盘）
      · 播放键在自动播放时会变成"方块"＝再点一下暂停。
      · 忘了哪个按钮是哪个？把鼠标停在图标上，会弹出文字提示（含快捷键）。

  工具栏最右边：
    背景 —— 下拉框：选桌面底图。自带 8 种：木纹 / 秋天 / 意式 / 海洋 / 冰雪 /
            黄昏 / 森林 / 夏至；把喜欢的图片（png/jpg）丢进 exe 旁边的
            backgrounds 文件夹，重启后也会出现在这里。
            默认那一项＝"默认（皮肤 / 木纹）"：跟着棋子皮肤的背景走，
            没有皮肤就用自带木纹。
    音效 —— 勾选框：走子 / 吃子 / 将军的音效开关（打勾＝开）。
    连线：未连接 —— 连线状态；纯手动打谱 —— 当前模式。

【左面板】两个标签页：
  「开局库」：显示当前局面在开局库里推荐的招法（着法、中文、次数、胜率、分值、来源）。
             上面有「加载…」「设置…」按钮，还有「启用库招」勾选框、库招策略下拉框、脱谱步数框。
             双击表格里某一行，就直接走这一步。
  「云库」：显示从网上云库查到的着法（着法、中文、分值、胜率、排序、备注），
           有「启用」「自动学习」勾选框、「查询」和「设置…」按钮。双击也能直接走这一步。

【中间棋盘】最大的那一块，是主视觉区。
  · 棋盘下方一行字会显示：该谁走、第几手、双方子力、是否重复局面。
  · 点一次棋子会出现"可以走哪里"的提示，再点目标位置落子；也能拖动棋子。
  · 被将军时，帅/将会出现红圈提示；最近走的那一步会有蓝框标出。
  · 在棋盘上点右键，会弹出一个快捷菜单：思考时间、搜索深度、对局模式、编辑局面、
    复制/粘贴 FEN、翻转棋盘，以及局面图片的复制/粘贴/导入/导出（很常用，记住它）。
  · 拖动窗口边缘可以把界面拉大，棋盘会自动变大。

【右面板】上下两块：
  上半：棋谱。
    · 最上面一行是棋谱信息（红方、黑方、结果、日期等）。
    · 如果打开的棋谱里有好几盘棋，会有一个下拉框让你切换。
    · 下面是着法列表：**第一行永远是「0. 初始局面」，点它就能直接回到开局**
      （以前必须点上一步，现在不用了）。点任意一手可以跳过去，右键可以设为主线/删除分支。
    · 着法后面如果出现"变×N"表示这里有 N 个分支，"✎"表示这一手写了评注。
    · 最下面是评注框，写完点「保存评注」。
    · 右上角有个"记谱"下拉框，可以切换中文/繁体/坐标/WXF 记谱显示方式。
  下半：引擎分析。
    · 一行小控件：思考（秒）· 深度 · 路线（推荐条数）。
    · 下面是深度、评分、判断、节点、速度、用时；再下面是胜率条、评分曲线、胜率曲线；
    · 最下面是"引擎推荐着法"列表，双击某一行就直接走那一步。

【底部状态栏】显示最近的操作提示、引擎状态、当前分析的深度与评分。


四、打谱（看棋、存棋）
------------------------------------------------

  · 新建棋局：顶部「新建棋局」，回到标准开局。
  · 打开棋谱：顶部「打开棋谱」→ 选 .xqf 或 .pgn 文件。
    只支持这两种格式；如果选了别的格式，程序会弹提示拒绝。
    PGN 里如果写着多盘棋，右栏会出现对局列表，点一下就能切换。
  · 逐手看棋：用「首 / 上一步 / 下一步 / 末」，或键盘 ← →、Home/End。
    点「播放」会自动播放，速度可以在右栏…（播放是固定间隔，想停下来再点一次「播放」）。
  · 写评注：跳到你想评论的那一手，在右栏评注框里写字，点「保存评注」。
  · 分支（变例）：走到某一手时改走别的着法，就会自动形成一条分支；
    在着法列表上右键可以"设为主线""删除这一手"，着法后面会显示"变×N"。
  · 保存棋谱：顶部「保存棋谱」→ 选保存位置与后缀：
      .pgn —— 通用棋谱文本，几乎所有象棋软件都认（含变例、评注、结果）。
      .xqf —— 象棋演播室格式（含变例与评注）。
    保存时按你当前选择的记谱方式（中文/繁体/坐标/WXF）写着法。
  · 回到开局：点着法列表最上面的「0. 初始局面」，一步到位。


五、引擎（皮卡鱼）怎么用
------------------------------------------------

  1. 加载引擎
     · 首次打开**什么都不用做**：程序自带皮卡鱼（随 exe 一起打包，包括神经网络权重），
       会自动把这个内置引擎加载好，直接就能用。
     · 要换引擎：点顶部「引擎」→ 在"引擎路径"里点「浏览…」选一个 UCI 引擎（比如新版皮卡鱼），
       再点「加载引擎」。想省事可以点「自动查找」。换过之后程序会记住你的选择，
       下次打开就用你选的那个引擎；想换回自带的，把"引擎路径"清空后点「自动查找」即可。
     · 皮卡鱼需要 pikafish.exe 和 pikafish.nnue（权重文件）放在同一个文件夹里，缺一个都跑不起来。
       自带的皮卡鱼已经配好权重，不用你操心。
     · 「已添加的引擎」列表会记住你用过的引擎，选中后点「切换到这个引擎」就换过去，
       点「移除」把它从列表里删掉（自带皮卡鱼会显示"（内置）"）。每个引擎的选项是各自单独保存的。
     · 引擎设置面板里**只有引擎自己的选项**（比如皮卡鱼的 Threads 线程数、Hash 内存、
       MultiPV 推荐条数、UCI_ShowWDL 显示胜率、Clear Hash 清空哈希、EvalFile 权重文件等），
       加载引擎时程序会自动探测并全部列出来，改完立刻生效，不用重启。
     · 这个面板里没有"难度滑块"之类自己造的东西：想让引擎弱一点，把右栏的「思考」秒数调小；
       想更强，把「思考」调大、在引擎选项里把 Threads 调大。
     · 点「重新探测选项」可以让程序重新问一遍引擎支持哪些选项。

  2. 三种模式（顶部三个按钮，随时可切）
     · 引擎执红：引擎走红方，你走黑方。轮到红方时，引擎会自己想、自己走（棋盘会自动翻成你这边在下）。
     · 引擎执黑：引擎走黑方，你走红方。轮到黑方时引擎自动走。
     · 分析模式：引擎**一直算、但不走棋**，实时给你最佳着法、评分和胜率，
       你可以自己走任意一方来研究；点"走这步"可以把推荐着法走到棋盘上。
     · 都不选（把当前模式再点一次取消）：纯手动打谱。引擎不走也不自动分析，
       想分析的时候点右栏「开始分析」（或按 F5）就行，这次分析会一直算到你点「停止分析」。
     · 引擎走棋的时间：右栏「思考（秒）」控制每步算多久；「深度」是搜索层数上限（0＝不限）；
       「路线」是要同时给几条推荐（1-12，默认 1）。
     · 评分怎么看：显示的是引擎给的**原始分值**（几十到几百，例如 +37、-152），
       正数=红方好，负数=黑方好；如果是绝杀会显示"红方 3 步杀"。


六、开局库与云库
------------------------------------------------

  1. 加载开局库（左栏「开局库」→「加载…」，或在「设置…」里添加）
     · 支持三种文件：.obk、.pfbook、.xqb（这三种牌子的库很多其实是同一种内部结构，程序都能读），
       以及 .xqf（棋谱库）。其它格式会被拒绝并提示。
     · 可以一次加载**多个库**，加载后左栏表格会随当前局面自动刷新：
       着法、中文记谱、出现次数、胜率、分值、来源（哪个库）。
     · 一个局面库里没有记录时，表格就是空的——这是正常的，说明这个局面已经"脱谱"了。
     · 「设置…」里可以：调整多个库的优先级（↑优先 / ↓靠后）、移除某个库、全部卸载、
       用当前棋谱建库、导出 OBK、以及「浏览库内容…」（把库里前 300 条原始记录列出来看）。
     · 「用当前棋谱建库」= 把你刚打开的棋谱（PGN/XQF）统计成一个开局库，可以再导出成 .obk。

  2. 启用库招与策略
     · 「启用库招」（默认打勾）：轮到引擎走棋时，如果当前局面在库里，引擎就按库走，
       这样开局更像人下的棋。取消打勾＝引擎完全自己算。
     · 「策略」下拉框（默认"最高分"），决定库里有多步候选时怎么挑：
         最高分 —— 挑库里分值最高的那一步；
         最高胜率 —— 挑库里胜率最高的那一步；
         正分数随机 ——在分值为正的候选里随机挑（走棋有变化，但不乱走）；
         完全随机 ——在库里所有候选里随机挑（变化最大，也最不讲究）。
     · 「脱谱」框：填一个手数 N（0＝不限）。意思是超过 N 手之后就不再使用库招，交给引擎自己算。
       例如填 20，就是前 20 手可以用库，之后都靠引擎。
     · 双击左栏表格里的某一行，就直接走这一步（自己研究时很方便）。

  3. 云库（左栏「云库」标签页）
     · 云库是网上的中国象棋云库（chessdb.cn），需要联网。
     · 「启用」＝打开云库查询；「查询」＝立刻查一次当前局面。
     · **「自动学习」（默认打开）**：打开后查询会带上"学习"参数，云库才会给出**全部**招法、
       分值和胜率（不打开只能看到一部分数据）；如果这个局面云库还没收录，
       它会接受这个局面去分析，所以要等几秒。不想联网提交局面就把这个勾去掉。
     · 超时默认 3 秒：网络不好导致查询失败时，可以在「设置…」里把"超时(秒)"调大（比如 8～15 秒）。
     · 「设置…」里还能：改接口地址、清空缓存、勾选"人机对战时优先走云库着法"
       （本地库没命中时，引擎会先走云库推荐的招法）。
     · 云库结果表格里：分值＝云库给的分；胜率＝这一手的历史胜率；排序＝云库内部的优先顺序；
       备注＝云库的简短说明；没收录的着法会写着"未收录"。
     · 左栏「开局库设置」里还有一个"左栏开局库同时显示云库结果"的勾选框，
       打开后云库的招法会一起显示在「开局库」表格里（来源列会写"云库"）。


七、界面设置（顶部「界面」按钮）
------------------------------------------------

  1. 五个开关（打勾＝开启，空框＝关闭）
     · 棋步提示箭头 —— 引擎推荐的着法要不要在棋盘上画箭头。
     · 棋盘线路数字 —— 棋盘四周的 1-9 / 一-九 坐标要不要显示。
     · 棋子阴影 —— 每颗棋子的**右下方**加一层淡淡的投影（像从左上角打光，
       和「鲨鱼象棋」那种立体感一样）。所有棋子、所有皮肤用同一种阴影，
       不用逐套皮肤设置；不想要就取消勾选，立刻恢复平面画法。
     · 底部状态栏 —— 底部那行提示文字要不要显示。
     · 音效 —— 走子、吃子、将军的音效开关（工具栏最右边也有一个"音效"勾选框，两处联动）。

  2. 棋盘主题（5 套配色）
     木纹 / 胡桃木 / 绿呢桌布 / 夜色 / 素纸。
     这里改的是棋盘底色、线条、河界、棋子牌面这一整套颜色。
     · 默认的"木纹"主题：整块棋盘和它周围都是浅棕色木纹（像真的实木棋盘摆在木桌上），
       楚河汉界中间是空的、没有竖线穿过。
     · 胡桃木也是木纹（颜色更深）；绿呢 / 夜色 / 素纸是纯色底。

  3. 棋盘大小
     · 滑块可以从 60% 调到 100%：100% 就是"撑满中间区域"，数值越小棋盘越小。
     · 三个快捷键按钮：小 60% / 中 80% / 撑满 100%。
     · 还有一个更快的办法：把鼠标放在棋盘上，**按住 Ctrl 滚滚轮**就能实时缩放。
     · 想让棋盘更大？把窗口拉大或者最大化，棋盘会自动跟着变大。
     · 100%（撑满）时棋盘上下左右也会自动留出约 6.5% 的空隙，
       保证**最上面一排和最下面一排的棋子都完整露出来**、不会被窗口边缘挡住。
       这也是默认尺寸，不用自己调；想再小一点就把滑块往左拉。

  4. 皮肤（棋盘 + 棋子的图片，可换很多套）
     · 皮肤放在程序旁边的 **skins 文件夹**里，一个子文件夹就是一套皮肤：
         skins\1-Ivory\        ← 一套
         skins\2-Jade\         ← 又一套
         里面放：background（整块棋盘区域的背景图）、ba/bb/bc/bk/bn/bp/br（黑方七子）、
                 ra/rb/rc/rk/rn/rp/rr（红方七子）、mask / mask2（可选，选中框和落点框）、
                 board（可选，有就用它当棋盘）、skin.json（对齐参数）。
         图片 BMP / PNG / JPG 都认，文件名大小写都行。
       ★ 程序自带了 78 套皮肤（已打包进 exe），即使不放 skins 文件夹也能直接用。
     · 用法：点顶部「界面」→「棋子皮肤」这一栏：
         「皮肤列表」下拉框里会列出 skins 里的所有皮肤，选一套就立刻换；
         转换脚本还在跑的时候，点一下旁边的「刷新」就能看到新出来的皮肤。
         选皮肤时，棋盘后面的整块背景也会换成这套皮肤的 background 图。
         不选皮肤（点「恢复自带」）就回到默认的浅棕色木纹背景。
     · 想让某套棋盘图对齐得准，就在那套皮肤的文件夹里放一个 skin.json，
       写明棋盘图里"8×9 网格"的精确位置（格式见 skins 目录里的
       「skins_skin_json_格式说明.txt」，或同名的说明文件）。
       没有 skin.json 时程序会自动检测。
     · 程序自带的 78 套皮肤都已经逐套校准过（skin.json 里的 grid 就是校准结果）：
         61 套直接用皮肤里的 board.png 当棋盘底，棋子正好压在画的交叉点上；
         17 套的 board.png 本身只有棋盘的一个角（图被放大或裁切过），
         这种图贴上必然错位，程序就改用**程序自画的棋盘 + 这套皮肤的材质配色**，
         棋子仍然用这套皮肤的棋子图 —— 所以 78 套都不会出现"棋子跟棋盘错位"。
       你新加的皮肤如果没有 skin.json，程序会自动检测；检测不出来就退回上一种画法
       （自带棋盘底 + 该皮肤材质配色），同样不会错位。
     · 想换回软件自带的画法：点「恢复自带」。
     · "选中棋子"的小框和"能走到哪里"的小框会用 mask / mask2；
       这两张图没提供就自动用自带的圆圈和绿点，不影响使用。


八、连线其他象棋平台（连到别的平台下棋）
------------------------------------------------

  1. 怎么连
     · 点顶部「连线」→ 光标变成圆圈，到对方象棋窗口（天天象棋 / QQ象棋 / 鹏飞象棋等）
       上点一下，选中它就开始了。
     · 程序每隔一段时间截一次图，认出对方走了哪一步，自动记到我们这边；
       「引擎执红 / 引擎执黑」模式下，引擎走出的招法会自动点到对方窗口里。
     · 想结束就点「断开」；窗口关了点「断开」再点「连线」重来即可。
     · 执红/执黑都自动换算：执黑时对方平台把棋盘转 180°，程序会跟着翻，
       识别到的局面和点出去的招法方向都不会反（「连线设置」里可手动改）。
     · 截图间隔、点击时长、后台模式、识别模型、棋盘区域这些参数，都在工具栏
       「连线设置」那个独立窗口里调。

  2. 识别稳不稳：规则校验 + 连续 N 帧确认（默认都开着）
     · 规则校验：认出来的局面必须先"像一盘合法的棋"才会被采用——
       每种子力数量不能超（车马炮相士各 2、兵卒 5、将帅各 1）、双方将帅都要在、
       士不能出九宫、相/象不能过河、棋子总数不超过 32、棋子不能挤在同一格。
       不满足的这一帧直接作废，等下一帧重认，不会把误读当真。
     · 智能确认：正常走子（就差一步合法着法）只要连续 2 帧一致就同步，
       第三帧用来兜底（万一对不上就自动重新确认）；异常情况（画面噪声、动画中间态、
       大跳变）仍然要连续 3 帧。这样"一闪而过的误识别"不会让棋盘乱跳。
     · 时间窗：同一个结果持续时间够久（默认 0.6 秒 × (帧数−1)，也就是走子 0.6 秒、
       异常情况 1.2 秒）也会直接确认，所以把扫描间隔调大不会让等待翻倍。
     · 开关在工具栏「连线设置」里：「规则校验」勾选框、「连续 N 帧确认」
       数字框和「或持续 N 秒」数字框。想更快可以把帧数调成 1，或把秒数调小。

  3. 出问题怎么看
     · exe 旁边有个 link_debug.log，按时间记录了每一帧的识别情况，例如
       "规则校验不通过：c×4>2（第 12 次扫描，这一帧作废）"、
       "棋盘发生变化 第1帧确认（需要 2 帧，正常走子）"、"棋盘变化已确认"、
       "对方走了 h0->g2"、"点出本程序着法" 等，能直接看出卡在哪一步。
     · 分不清是"看错"还是"点错"，就看日志里的坐标行：识别出的棋盘网格是
       "识别网格 x,y 格 cx,cy"，点出去的是"已点击 xx 客户区坐标 (x,y)｜坐标系数 ×1.50
       → 实际点 (x,y)"。识别对、落点也压在交叉点上，就说明整套换算都对得上。
     · 换电脑/换分辨率以后建议先点一次「连线设置 → 预览识别」，一眼就能看出
       棋盘认没认出来（详见第八节第 5 条）。

  4. 速度和 CPU（这一版专门优化过）
     · 上面这些防误判机制只在"识别对方走子"时等一两帧；**本程序自己（含引擎）
       走出的招法永远立刻点出去**，不受影响。
     · 三项提速：推理改用 4 线程（比原来 2 线程快约 1.8 倍）；画面和上一帧完全一样时
       直接沿用上一帧的识别结果（待机时几乎不占 CPU）；连接时先做一次空推理预热，
       省掉第一次识别的卡顿。
     · 想让同步更快，把「扫描间隔」调到 0.3～0.5 秒即可，配合上面的优化 CPU 也不吃力。

  5. 换电脑 / 换分辨率 / 换屏幕缩放（1080p、2K、4K 都支持）
     · 程序会**自动检测屏幕的实际分辨率和系统缩放**，并按比例换算识别范围与点击坐标：
       1080p + 100% 缩放＝坐标系数 ×1.00（和老版本完全一样），2K + 125%＝×1.25，
       2K + 150%＝×1.50，4K + 200%＝×2.00。你不用改任何设置，拷到新电脑上直接连线即可。
     · 连接成功后状态栏（左上角）会显示「坐标×1.50」，说明已经按缩放换算过；
       系统缩放是 100% 时不显示这一项。
     · 「连线设置」里有「屏幕与坐标换算」一栏，会写清楚：
       屏幕实际分辨率（以及程序看到的逻辑分辨率）、系统缩放百分比、当前坐标系数、
       目标窗口客户区的大小和位置。
     · 换分辨率 / 换平台后不确定识别对不对，就点「连线设置 → 预览识别」：
       程序会当场抓一帧对方窗口的画面，把识别到的棋盘网格画出来，并列出认出几个棋子。
       图上有蓝色网格、棋子数对（开局 32 个）就说明"看"这一半没问题。
       预览窗口会跟着「连线设置」窗口摆，不会跑到屏幕外面去。
     · 棋盘区域（左/上/宽/高）是**百分比**，默认 0/0/100/100＝整个窗口，让程序自己在
       整张截图里找棋盘 —— 这样换分辨率不用重设。如果对方窗口里棋盘只占一小块，
       可以把区域缩小到刚好圈住棋盘（比如左 25、上 10、宽 50、高 80），识别会更稳。
     · 目标窗口拖到哪、缩放到多大、甚至拖到另一块显示器上，程序每次都按它**当前**的
       位置去截图、去点击，不会记死坐标。
     · 排查用的 link_debug.log 每次连接都会写一行环境信息，例如
       "连线环境：屏幕 2560x1440（本程序看到 1707x960）｜系统缩放 1.50x（DPI 144）｜
        本程序DPI感知=0｜目标DPI感知=2｜目标DPI=144｜客户区=1600x1200@100,80｜
        消息坐标系数=1.50" —— 把这行发过来就能定位大多数"某台电脑上连不上"的问题。


九、编辑局面与局面图片
------------------------------------------------

  1. 编辑局面（顶部「编辑局面」）
     · 棋盘下面会出现一条工具条：左边是各种棋子画笔（红黑各一套）和"擦"。
     · 左键点棋盘＝把当前选中的棋子放上去；**右键点棋盘＝把那格的棋子删掉**。
     · 工具条上还有：清空棋盘 / 初始局面 / 交换红黑 / 红先·黑先 / FEN 输入框（可粘贴、可复制）/
       开始对局 / 取消。
     · 摆好之后点「开始对局」，程序会检查局面是否合法（比如必须各有一个帅/将），
       不合法会告诉你哪里有问题。

  2. 局面图片（在棋盘上点右键就能看到这几项）
     · 复制局面图片 —— 把当前棋盘画成一张图放进剪贴板，可以直接粘到聊天窗口或文档里；
     · 导出局面图片… —— 存成 PNG 或 JPG 文件；
     · 粘贴局面图片（自动识别）—— 先从别处复制一张棋盘截图，再用这个功能，
       程序会认出棋子并弹出识别结果，你确认后进入编辑局面核对，没问题就点「开始对局」；
     · 从图片文件导入局面… —— 选一张存好的棋盘图片来识别。
     · 也可以直接把图片文件（png/jpg/bmp/gif/webp）**拖到窗口上**，效果一样；
       拖 .pgn / .xqf 文件进来则会按棋谱导入。
     · 小提示：图片里最好只有棋盘、线条清楚，识别最准；如果认得不全，进编辑局面手动补几个子就行。

十一、常见问题（Q & A）
------------------------------------------------

Q1：双击 exe 没反应 / 一闪就没了？
   · 确认 exe 是从桌面「静夜象棋界面」文件夹里双击的（程序要能找到同目录下的 engine 文件夹）；
   · 有些安全软件会拦截新程序，允许一下再试；
   · 如果窗口开了但看不到，按 Alt+Tab 看是不是被别的窗口挡住了。

Q2：右下角显示"未加载引擎"，或者引擎一直不动？
   · 程序自带皮卡鱼，正常情况打开就自动加载好了，不用自己放引擎文件；
   · 如果显示没加载：点顶部「引擎」→「自动查找」，或者「浏览…」手动选 pikafish.exe，再点「加载引擎」；
   · 想用自己下载的引擎时：那个引擎的 exe 和它的权重文件（如 pikafish.nnue）必须在同一个文件夹；
   · 引擎设置里如果提示错误，按提示处理（常见的是缺 nnue 权重文件）；
   · 如果是"纯手动打谱"模式（三个模式按钮都没选），引擎本来就不会自动走子，这是正常的：
     点「引擎执红 / 引擎执黑 / 分析模式」其中一个就行。

Q3：为什么我走了一步，引擎没反应？
   · 看你选的是哪个模式：只有"引擎执红/引擎执黑"时引擎才会自己走棋；
   · 分析模式只给提示不走棋，双击右栏"引擎推荐着法"里的某一行可以让它走（你自己走）；
   · 引擎正在思考时你不必等，但如果棋局结束了（将死/困毙），引擎就不会再走了。

Q4：加载了开局库，为什么表格是空的？
   · 空表格＝这个局面库里确实没有记录（叫"脱谱"），换个常见开局试试（比如先走炮二平五）；
   · 确认「启用库招」是打勾的（打勾才是开）；策略、脱谱步数也检查一下：
     "脱谱"填了 0 表示不限，填了较小的数字则超过该手数后就不再查库；
   · 如果库文件本身是"演示库"（只有几条记录），能查到的局面自然很少；
   · 点「设置…」→「浏览库内容…」可以看到库里到底有些什么记录。

Q5：库里显示的"分值""胜率"是什么意思？
   · 分值＝库里给这一步的分数（不是引擎评分，各库自己定义，越大表示库里越看好）；
   · 胜率＝库里这一步的历史胜率（胜 1 分、和 0.5 分这样算出来的）；
   · 如果是"-"，说明这个库没有存胜负统计（有些库只存分值），不是软件出错。

Q6：勾选了「启用库招」，怎么引擎走的不是库里的招？
   · 先看这个局面在左栏表格里有没有记录，没有记录当然就用不了库招；
   · 如果"脱谱"手数设置得比较小，可能已经超过范围，把 0 填回去（不限）；
   · 如果开启了"优先走云库着法"，云库推荐会优先；
   · 库里的招法必须是在当前局面下合法的一步，程序会自己校验，不合法的记录不会被采用。

Q7：云库查不到东西 / 一直转圈？
   · 云库需要联网，先确认能上网；
   · 云库没收录这个局面时，结果会显示"未收录"，
     这时打开「自动学习」再查一次，云库会去分析这个局面（要等几秒）；
   · 网络慢就把超时调大：左栏「云库」→「设置…」→"超时(秒)"改成 8~15；
   · 还是不行就点"清空缓存"再查（有时是旧缓存的问题）。

Q8：界面右下角显示"评分 +37"这种数字，是分数吗？
   · 是引擎给的原始分值。正数表示红方好，负数表示黑方好，数值越大优势越明显；
   · 例如 +37 是红方略好，-152 是黑方明显好；如果是"红方 3 步杀"表示红方三步内将死对方。

Q9：换了皮肤，但棋盘/棋子没变？
   · 皮肤要放在程序旁边的 skins 文件夹里，每套一个子文件夹（14 个棋子图必须齐全）；
   · 点「界面」→「皮肤列表」旁边的「刷新」，再从下拉框里选一套；
     右边会显示"共 N 套"，选中的皮肤名会显示在「棋子皮肤」后面；
   · 棋盘图有偏移（棋子不在交叉点上）时，看该文件夹里有没有 skin.json，
     没有的话程序会尝试自动对齐；都不行就用自带木纹棋盘（棋子照样能换）；
   · 点「恢复自带」可以随时回到系统自带的画法。

Q10：想回到开局那一手，怎么办？
   · 直接点右栏着法列表最上面的「0. 初始局面」；或者按 Home 键；或者点顶部的「首」。

Q11：打开棋谱后中文变成乱码？
   · 程序会自动尝试 UTF-8 和 GB18030 两种编码；如果还是乱码，
     请用记事本把棋谱"另存为"UTF-8 再打开；
   · 也可以把棋谱发给我看一下（标题栏里有我的 QQ）。

Q12：走棋时"我想到的那一步"不给走？
   · 说明这一步在当前局面下不合法（比如会被将军、或者棋子走法不对/被挡住）；
   · 程序会拒绝不合法着法，这是保护，避免把棋谱记错。

Q13：分析时界面有点卡？
   · 把右栏「思考（秒）」调小一点，或在「引擎」里把 Threads 调小（例如 4）、
     MultiPV（路线）保持 1；不要长期挂在"分析模式"上；
   · 也可以把「界面设置」里的"棋步提示箭头"关掉，老电脑会更流畅。

Q14：软件需要联网吗？会上传我的东西吗？
   · 打谱、分析、人机对战、开局库都不需要联网，也不会传东西出去；
   · 只有"云库"需要联网：打开「自动学习」时会把**当前局面**提交给云库分析（这是云库的要求），
     不想提交就把"自动学习"的勾去掉。

Q15：设置改好了，下次打开又变回默认了？
   · 目前的设置是"本次运行有效"，重启后会回到默认值（云库自动学习开、超时 3 秒、
     路线 1、启用库招开、策略最高分、木纹主题、棋盘 100%）。
   · 如果你希望把皮肤、主题、大小这些永久记住，跟我说一声，我加一个配置文件保存。
